# Activity 13.2: Implementing Time Loops

## Overview

This activity demonstrates how to implement time loops and timers in Python. A nested dictionary is created from multiple lists using the `zip()` function, and execution is delayed using both `time.sleep()` and the `threading.Timer()` class.

The activity introduces key concepts that will later be used to schedule Change Data Capture (CDC) operations.
