# Docker Commands

## List Running Containers

```bash
docker ps
```

## List All Containers

```bash
docker ps -a
```

## Create Container

```bash
docker run
```

## Stop Container

```bash
docker stop <container_name>
```

## Remove Container

```bash
docker rm <container_name>
```

## Remove Forcefully

```bash
docker rm -f <container_name>
```
